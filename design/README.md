# 🎨 Design e Identidade Visual: Rede Delas

Este diretório contém os artefatos visuais que compõem o ecossistema da Rede Delas.

## 📂 Estrutura do Diretório

*   **`branding/`**: Contém o estudo de logotipo e a paleta de cores técnica (SVG).
*   **`wireframes/`**: Esboços de baixa fidelidade realizados no Whimsical, cobrindo as telas do sistema.

## 🌈 Identidade Visual

A paleta de cores foi baseada no equilíbrio entre tecnologia (Roxos/Turquesa) e acolhimento (Rosa/Peach). O guia detalhado de cores pode ser encontrado no arquivo `branding/paleta_cores.svg`.

## 📐 Wireframes (Baixa Fidelidade)

Os wireframes documentam a Arquitetura da Informação e o Fluxo de Navegação.

*   **Principais fluxos mapeados:** Onboarding, Mentoria (Mentoranda/Mentora), Agenda de Eventos e Painel Administrativo.
*   **Próxima Etapa:** Desenvolvimento do Protótipo de Média Fidelidade no Figma.
